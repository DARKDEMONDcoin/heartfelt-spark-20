# ضبط حركة الغلاف وتجديد قسم «المنصة نفسها»

## النتيجة
- حركة مستمرة ومرئية للغلاف الملون، هادئة بما يكفي ألا تشتت عن النص.
- أربعة مشاهد مختلفة بوضوح للمتاجر والمطاعم والعيادات والعقار، بدل إعادة استخدام صور واجهات عامة.
- كل مشهد يجمع صورة قطاع احترافية مع طبقة من واجهة سهل توضّح كيف تخدم المنصة هذا النشاط.

## التنفيذ
1. تحريك الغلاف نفسه بمسار بطيء قصير مع إبقاء حركة الضوء والخطوط داخله، وضبط النسخة المحمولة بشكل مستقل.
2. إنشاء أربع صور أصلية عالية الجودة ومتناسقة فنياً: منتج متجر عربي، مطعم وقت الخدمة، عيادة حديثة، وعقار راقٍ.
3. إعادة بناء لوحة كل خيار بتكوين خاص: صورة رئيسية، مؤشر تشغيل، مهمة نشطة، ونتيجة مرتبطة بالنشاط؛ مع انتقال ناعم عند تبديل التبويب.
4. إبقاء النصوص والألوان بهوية سهل الحالية وعدم إدخال ادعاءات أو علامات تجارية خارجية.
5. اختبار الحركة والتبديل بصرياً على 1280px و451px، ومراجعة القصّ والتباين وعدم وجود تمدد أفقي أو أخطاء.

## تفاصيل تقنية
- الصور ستُحفظ ضمن أصول المشروع وتُحمّل عند الحاجة.
- الحركة ستستخدم CSS transform فقط لتحافظ على السلاسة، وستحترم إعداد تقليل الحركة.
- سيظل رابط «شاهد الحل الكامل» لكل نشاط يعمل على مساره الحالي دون تغيير منطق الصفحات.
